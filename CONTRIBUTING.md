# Contributing

Before you start, please read [`instructions.md`](./instructions.md).

All pull requests and repository changes should follow the guidelines and tips defined in [`instructions.md`](./instructions.md).

## Quick checklist

- [ ] I read [`instructions.md`](./instructions.md) before implementing changes.
- [ ] My changes follow the best practices from [`instructions.md`](./instructions.md).
- [ ] No changed file exceeds 800 lines; larger changes are split into modules/files.
- [ ] My pull request description explains how the change aligns with those guidelines.
