# camera-surveillance-stack-demo

A standalone static GitHub Pages demo for a playful surveillance dashboard mockup.

## What is included

- simple dashboard UI
- 2 fake camera panels using local animated SVG feeds
- random motion/activity indicators
- mock event list with playful cat-detection events
- no backend required

## Run locally

Open `index.html` directly in your browser, or serve the folder with any static server.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save.

After deployment finishes, the site will be available at:

`https://marcinator2.github.io/camera-surveillance-stack-demo/`
