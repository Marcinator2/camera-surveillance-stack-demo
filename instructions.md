# Project instructions and best practices

This document is a required reference for contributors (including Copilot and other automation).

## Scope

This repository is a static demo project for GitHub Pages (HTML/CSS/JS only, no backend).

## Development guidelines

1. Keep changes small, focused, and easy to review.
2. Prefer simple, dependency-free solutions whenever possible.
3. Do not break the existing demo behavior while extending UI or content.
4. Keep files readable and consistent with existing naming/style.
5. Use relative paths for assets (for local use and GitHub Pages compatibility).

## Pull request expectations

1. Explain what was changed and why.
2. Keep PRs aligned with these instructions.
3. Avoid unrelated refactoring in feature/content PRs.
4. Verify the demo works locally before submitting.
